# 🌌 보이저스 노트 (Voyager's Note) 정기 구독 폼 시스템

**🔗 배포 주소 :** https://hello2ruda.github.io/uiuxprogramming/

## 1. 서비스 소개 및 사용자 목표
- **서비스 목적:** 사용자의 취향에 맞춘 우주 관련 아티클을 매주 큐레이션하여 이메일로 제공합니다.
- **주요 사용자:** 밤하늘 관측에 낭만을 느끼는 일반인 및 거대한 우주 산업의 흐름을 쫓는 전문가
- **핵심 행동:** 사용자 이름과 이메일을 기입하고, 원하는 궤도를 선택하여 정기 구독 폼 양식을 제출합니다.
- **완료 조건:** 유효성 검사 통과 후 맞춤형 '보이저 가상 탑승권'이 발급되며, 기존 입력 폼은 숨김 처리됩니다.

## 🚀 7주차 중간고사(응용 구현) 새로 추가된 기능
기존의 단순한 구독 완료 메시지 출력을 넘어, **'가상 탑승권(Boarding Pass) 발급' 및 '탑승 취소 후 궤도 재설정'**이라는 새로운 사용 경로를 추가하여 중간 프로토타입을 완성했습니다.

### 📌 사용자 행동, 조건 검사 및 상태 피드백
**[새로운 경로 1] 구독 폼 제출 (탑승권 발급)**
- **사용자 행동:** 폼 양식을 채우고 '탑승하기' 버튼 클릭
- **확인할 조건:** 필수 항목(이름, 이메일, 플랜) 누락 여부 검사
- **오류 반응:** 누락 시 기본 제출을 막고 붉은색 경고 텍스트로 안내하여 수정 유도
- **성공 반응:** 유효성 검사를 통과하면 기존 폼이 화면에서 숨겨지고(`display: none`), 사용자의 입력값과 랜덤 생성된 정보(게이트, 좌석, 탑승 시간)가 결합된 가로형 '보이저 탑승권' UI가 홀로그램 승인 도장 애니메이션과 함께 나타남.

**[새로운 경로 2] 탑승 취소 버튼 클릭 (취소 및 수정 경로)**
- **사용자 행동:** 탑승권 하단의 `[탑승 취소 및 궤도 재설정]` 점선 버튼 클릭
- **확인할 조건:** `confirm()` 창을 띄워 탑승 취소 의사를 한 번 더 검사
- **취소 반응:** 취소 확정 시 탑승권 UI가 숨겨지고, 구독 폼 화면이 다시 나타나며 하단에 *"탑승이 취소되었습니다. 궤도를 다시 확인하고 설정해 주세요."* 라는 피드백 텍스트 노출
- **다음 행동 (값 유지):** 이전 단계(폼)로 돌아왔을 때, 기존에 입력해 둔 값(이름, 이메일, 선택 궤도)이 초기화되지 않고 그대로 유지되어 사용자가 재입력의 번거로움 없이 즉시 궤도를 수정(다음 행동)할 수 있음.

### 🧪 테스트 기록 (직접 시험한 결과)
- **정상 경로:** 필수 정보 입력 후 제출 -> 폼 숨김 처리 및 가로형 탑승권 노출 -> 0.3초 뒤 승인 도장 애니메이션 정상 출력 확인 완료.
- **오류 경로:** 이메일 누락 후 제출 -> 폼 제출 차단 및 "이메일 주소를 입력해 주세요." 에러 피드백 정상 출력 확인 완료.
- **취소 및 수정 경로:** 탑승권 화면에서 [취소] 버튼 클릭 -> 확인(Confirm) 수락 -> 탑승권 숨김 및 폼 복귀 -> 취소 피드백 텍스트 노출 및 기존 입력값(이름, 이메일, 궤도)이 지워지지 않고 정상 유지됨 확인 완료.
- **반응형 테스트:** 모바일(390px) 기기에서 조작 시 가로형 티켓 내부 2단 정보가 세로로 정상 전환되며, 잘림 현상 없이 조작 가능함을 확인 완료.

## 히스토리

### 1. 다양한 DOM 이벤트 및 다중 화면 변화 구현
사용자의 상호작용(Interaction)에 따라 화면의 문구와 스타일이 실시간으로 반응하도록 `input`, `change`, `click` 세 가지 이벤트를 구현했습니다.

- **input 이벤트 (이름 실시간 동기화)**
  * 조건: 폼의 '닉네임' 필드에 타이핑을 할 때 발생
  * 화면 변화 1 (문구): 폼 상단에 '[입력한 이름]님, 환영합니다! 궤도를 설정해 주세요.' 라는 맞춤형 환영 문구가 즉각적으로 노출됨.
  * 화면 변화 2 (스타일): 한 글자 이상 입력 시, 해당 환영 문구의 색상이 기본 회색에서 활성화된 네온 블루(#00d2ff) 색상으로 부드럽게 변경됨.

- **change 이벤트 (맞춤형 버튼 상태 동기화)**
  * 조건: 구독 플랜(Select 요소)에서 옵션을 변경할 때 발생
  * 화면 변화 1 (문구): 하단 제출 버튼의 텍스트가 선택한 플랜에 맞게 "스타라이트 탑승하기" 또는 "딥 스페이스 탑승하기"로 변경
  * 화면 변화 2 (스타일): 제출 버튼의 배경색이 선택한 궤도의 성격에 맞게 변경됨. 선택 해제 시 다시 기본 다크 슬레이트 색상으로 복구

### 2. 정보 전환 탭(Tab) UI 구현
- **click 이벤트:** '오직 당신의 궤도에 맞춘 컨텐츠' 섹션에 3개의 탭을 구성하여 클릭 시 정보를 전환
- **작동 방식:** 각 탭 버튼 클릭 시, JavaScript를 통해 모든 콘텐츠를 숨기고 클릭한 버튼에 해당하는 콘텐츠만 화면에 노출
- **시각적 피드백:** 현재 선택된 활성화 탭 버튼은 테두리가 밝은 파란색으로 변경되고 배경이 밝아져 다른 탭들과 명확히 구분됨.
