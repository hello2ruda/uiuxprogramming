# 4주차 반응형 수정 기록

## 확인한 문제
좁은 화면 환경에서 컨텐츠가 올바르게 보이지 않는 문제 발생

## 수정한 내용
일정 px 이하에서 네비게이션 메뉴, 카드, 폼 등을 한 열로 보이도록 배치

## 달라진 점
좁은 화면 환경에서 가로 스크롤 없이 내용을 읽고 입력 가능
