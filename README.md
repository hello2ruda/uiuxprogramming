# 5주차 반응형 수정 기록

## 확인한 문제
구독 완료 알림이 뜨지 않아 사용자가 구독 여부 확인이 어려움

## 수정한 내용
구독 실패 시 폼에 부족한 정보가 무엇인지 알려주고, 구독 완료 시 구독 확인 알림 및 구독 버튼 비활성화

## 달라진 점
사용자가 직관적으로 구독 시 더 필요한 정보들 및 구독 완료를 확인 가능

# 4주차 반응형 수정 기록

## 확인한 문제
좁은 화면 환경에서 컨텐츠가 올바르게 보이지 않는 문제 발생

## 수정한 내용
일정 px 이하에서 네비게이션 메뉴, 카드, 폼 등을 한 열로 보이도록 배치

## 달라진 점
좁은 화면 환경에서 가로 스크롤 없이 내용을 읽고 입력 가능

# 3주차 CSS 수정 기록

## 수정한 내용
기능이 없는 카드에 호버 이펙트를 제거하기 위해 .feature-list:hover를 제거

## 수정 이유
차후에 페이지를 연결할 예정이나 현재는 기능이 없으므로 사용자에게 혼동을 주지 않기 위해 삭제
