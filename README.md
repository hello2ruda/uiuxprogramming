# 🌌 보이저스 노트 (Voyager's Note) - 뉴스레터 구독 랜딩 페이지

## 📌프로젝트 소개
우주를 읽는 두 가지 시선, '보이저스 노트'의 뉴스레터 정기 구독을 위한 반응형 웹 페이지입니다. 사용자의 관심사에 따라 감성 큐레이션과 심층 분석 리포트 중 원하는 궤도를 선택할 수 있습니다.

---

##  5주차 과제 구현 내용

### 1. 다양한 DOM 이벤트 및 다중 화면 변화 구현
사용자의 상호작용(Interaction)에 따라 화면의 문구와 스타일이 실시간으로 반응하도록 'input', 'change', 'click' 세 가지 이벤트를 구현했습니다.

* input 이벤트 (이름 실시간 동기화)**
  * 조건: 폼의 '닉네임' 필드에 타이핑을 할 때 발생
  * 화면 변화 1 (문구): 폼 상단에 '[입력한 이름]님, 환영합니다! 궤도를 설정해 주세요.' 라는 맞춤형 환영 문구가 즉각적으로 노출됨.
  * 화면 변화 2 (스타일): 한 글자 이상 입력 시, 해당 환영 문구의 색상이 기본 회색에서 활성화된 네온 블루(#00d2ff) 색상으로 부드럽게 변경됨.

* change 이벤트 (맞춤형 버튼 상태 동기화)**
  * 조건: 구독 플랜(Select 요소)에서 옵션을 변경할 때 발생
  * 화면 변화 1 (문구): 하단 제출 버튼의 텍스트가 선택한 플랜에 맞게 "스타라이트 탑승하기" 또는 "딥 스페이스 탑승하기"로 변경
  * 화면 변화 2 (스타일): 제출 버튼의 배경색이 선택한 궤도의 성격에 맞게 변경됨. 선택 해제 시 다시 기본 다크 슬레이트 색상으로 복구

### 2. 정보 전환 탭(Tab) UI 구현
* click 이벤트: '오직 당신의 궤도에 맞춘 컨텐츠' 섹션에 3개의 탭을 구성하여 클릭 시 정보를 전환
* 작동 방식: 각 탭 버튼 클릭 시, JavaScript를 통해 모든 콘텐츠를 숨기고 클릭한 버튼에 해당하는 콘텐츠만 화면에 노출
* 시각적 피드백: 현재 선택된 활성화 탭 버튼은 테두리가 밝은 파란색으로 변경되고 배경이 밝아져 다른 탭들과 명확히 구분
